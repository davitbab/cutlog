⇅Sync via GitHub

Everything, in one file. On iPhone pick Save to Files.

⇩Import

Replaces everything here. With sync on, the next sync merges it into your repo.

⌫Reset

Deletes everything here, and from your repo if sync is on. Export first — this cannot be undone.
