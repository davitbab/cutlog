Nutrition engine

Where the calories come from on this device.

Sync via GitHub

Keeps one log.json in a repo you own, so every device reads and writes the same data and nothing is lost when a browser clears its storage. Use a private repo and a fine-grained token limited to that one repo with Contents: Read and write. The token is typed here on each device, stored only on that device, and is never part of an export — never paste it into the HTML, which is public. Keep the data repo private even when the repo serving this page is public; they can be two different repos.

Goal

Every number, the chart and the projection recalculate from these four.

Export

Save a file with every weigh-in, food entry and remembered food. Keep it in Files, iCloud or Drive — this is your safety net and how you move to another device. On iPhone and iPad this opens the share sheet: choose Save to Files. If the file just opens on screen instead, use Copy & paste backup below — it carries exactly the same data.

Import

Load an exported file. This replaces everything currently in the app — and if sync is on, the next sync merges it into your repo rather than replacing what is there.

Copy & paste backup

If files are awkward, move the data as text instead.

Reset

Deletes every weigh-in and food entry, and if sync is on it deletes them from your repo and every other device too. Back up first — this cannot be undone.
